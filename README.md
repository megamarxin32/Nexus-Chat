## ✨ Descripción General

**Nexus Chat** es una aplicación moderna de mensajería en tiempo real y centro de colaboración diseñada para ofrecer la máxima privacidad, productividad y facilidad de uso tanto en computadoras como en dispositivos móviles.

Combina **seguridad criptográfica de extremo a extremo (E2EE)**, **inteligencia artificial contextual (Google Gemini)** capaz de distinguir a los participantes de una conversación, **integración fluida con Google Workspace** (Gmail, Drive, Docs, Calendar y videollamadas Meet en 1 clic) y un potente **sistema multicuenta para PC** que permite alternar perfiles sin cerrar sesión.

---

## 🚀 Características Principales

### 🔒 Cifrado Extremo a Extremo (E2EE)
- **Zero-Knowledge Architecture:** Las claves de cifrado y las huellas criptográficas se generan en el dispositivo del cliente.
- **Huella Digital de Verificación:** Cada dispositivo cuenta con una huella única (Fingerprint E2EE) verificable entre los miembros del chat.
- **Protección Antisuplantación:** Verificación de propietario mediante código PIN de seguridad y alertas contra duplicación no autorizada de cuentas.

---

### 🔑 Identidad Unificada (Google OAuth + Login Clásico)
- **Una sola cuenta por correo:** Puedes acceder a la misma cuenta indistintamente a través de **Google OAuth oficial** (con selector libre de cualquier cuenta) o mediante **credenciales clásicas de usuario y contraseña**.
- **Sin cuentas duplicadas ni conflictos:** Todo tu historial de mensajes, canales, configuraciones y archivos en la nube permanecen sincronizados bajo una identidad única e indivisible.
- **Selector de cuentas oficial de Google:** La ventana emergente oficial de Google permite escoger libremente entre cualquiera de tus cuentas registradas en el navegador, sin forzar una cuenta específica.

---

### 💻 Soporte Multicuenta Simultánea en PC
- **Múltiples perfiles en la misma computadora:** Agrega diferentes cuentas (personales, de trabajo o de prueba) en la barra lateral sin tener que cerrar la sesión previa.
- **Cambio instantáneo en 1 clic:** Alterna rápidamente de una cuenta a otra conservando el estado de cada una.
- **Cierre de sesión seguro:** Si decides salir de una cuenta, la sesión se termina de inmediato en el cliente y sincroniza los cambios pendientes antes de solicitar nuevas credenciales.

---

### 🤖 Asistente Inteligente Gemini 2.5
- **Diferenciación de participantes:** El asistente analiza las conversaciones grupales identificando claramente quién es **Tú** y quiénes son los demás interlocutores (**Persona A, Persona B, Persona C...**).
- **Resúmenes contextuales inteligentes:** Extrae acuerdos clave, tareas pendientes y compromisos individuales en segundos.
- **Generación de respuestas rápidas y redactores:** Sugerencias automáticas adaptadas al tono del equipo.

---

### 💼 Suite Google Workspace y Meet
- **Videollamadas Google Meet:** Inicia salas de reunión instantáneas con un solo clic directamente desde cualquier conversación.
- **Gestión de Archivos de Drive:** Visualiza y vincula documentos de Google Docs, Hojas de cálculo y Presentaciones.
- **Sincronización con Calendar y Tareas:** Mantén los eventos de tu equipo organizados sin salir de la plataforma.

---

### ☁️ Sincronización en la Nube y Modo Sin Conexión
- **Espejo local (Offline-First):** Lee y escribe mensajes incluso sin conexión a Internet; los cambios se sincronizan en cuanto se restablece la red.
- **Canal de difusión en tiempo real (BroadcastChannel):** Las pestañas abiertas en el mismo dispositivo se actualizan simultáneamente.
- **Indicador de estado visual:** Monitorea en vivo si tu sesión está `Sincronizada`, `Sincronizando` o `Sin Conexión`.

---

### 🔋 Ahorro de Datos y Modo Ultra OLED
- **Modo Ultra Ahorro:** Reduce drásticamente el consumo de megabytes pausando descargas automáticas de multimedia pesada.
- **Tema Negro OLED Verdadero (#000000):** Optimizado para pantallas AMOLED con mínimo consumo de batería y confort visual prolongado.

## ⚡ Instalación y Ejecución Local

Sigue estos pasos para ejecutar el proyecto en tu máquina de desarrollo:

### 1. Clonar el repositorio
```bash
git clone https://github.com/megamarxin32/Nexus-Chat.git
cd Nexus-Chat
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno (Opcional)
Copia el archivo de ejemplo y añade tus claves de API si deseas utilizar funciones avanzadas del servidor:
```bash
cp .env.example .env
```

```env
# Clave de Google Gemini API (servidor)
GEMINI_API_KEY=tu_api_key_aqui
```

### 4. Iniciar el entorno de desarrollo
```bash
npm run dev
```
Abre tu navegador en `http://localhost:3000` (o el puerto indicado en la consola).

### 5. Compilar para producción
```bash
npm run build
```
